# Open-source plan

## Licensing

- **Application code, clinical workflow, observation model:** Apache License 2.0.
- **Documentation and implementation guide:** CC BY 4.0.
- **NdaY' Enterprise names, logos, and trademarks:** excluded from every licence.
- **Patient data, images, and household locations:** never public.

## Release milestones

1. Publish the repository with the working workflow and synthetic sample data.
2. Add an implementation guide and acceptance tests.
3. Publish hardware designs and flight procedures only after safety and regulatory review.
4. Independent deployment test by a qualified third party.

No public release has been made yet. Brand assets must be replaced or licensed before any
redistribution of a branded build.
